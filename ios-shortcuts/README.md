# iPhone 15：LINE 通知全文記帳

不需要 Apple Intelligence 或裝置端模型。捷徑只傳送整段付款通知，沿用小帳 GAS 的語音佇列與背景 AI 審查，再寫入原本 Google Sheet。沒有金額草稿，不會先記成 0 元或亂猜分類。

## 簡單版（本次使用這個）

檔案：`dist/小帳LINE簡單記帳.shortcut`。手機上原有的小帳網頁 App 照常使用，不用另外安裝記帳 App。

1. 匯入捷徑，貼入「小帳 → 設定 → 綁定手機 → 複製綁定連結」的完整連結，取代第一個文字欄；不要把操作說明當成連結。
2. 捷徑包含 iOS 27 的「收到通知」觸發器，但 App 與篩選是裝置上的選擇，仍需選 LINE，標題包含 `LINE錢包`、訊息包含 `付款完成`。如果匯入未保留觸發器，直接在編輯器加入同一通知條件。
3. 通知文字輸入應是通知的內文／訊息；不需裝置端模型，不固定餐飲分類。

先更新下述新版 GAS。簡版只發出一次請求，不存檔、不自動重送、不顯示虛假的「記帳成功」。網路錯誤或回應遺失時先查看 Sheet／佇列，勿直接重跑同一通知；新執行會產生新 ID。請停用舊的同類通知自動化，避免兩套同時記帳。真實通知與鎖屏執行仍需在你的 iPhone 驗收。

產生簡版：`node ios-shortcuts/build.mjs --simple`。下面是原完整版的設定，簡版不用匯入重送捷徑或允許檔案存取。

## 先更新 GAS

1. 把本專案 `gas/invoice-proxy.gs` 貼到原 GAS 專案。
2. 管理部署 → 編輯既有網頁應用程式 → 新增版本 → 部署，保留原 `/exec` 網址。
3. 確認已設定 `GEMINI_API_KEY`；執行一次 `installBackgroundProcessing` 並完成授權。

本版支援 2048 字原文與穩定送出 ID。捷徑會先檢查能力；舊 GAS 沒有更新時保留待送檔，不會送出交易。

## 匯入檔案

將 `dist/小帳LINE通知記帳.shortcut` 與 `dist/小帳LINE重送.shortcut` 透過 AirDrop 或私人 iCloud Drive 傳到 iPhone，在「檔案」App 點開並加入捷徑。

兩個捷徑的設定問題都貼上：小帳 → 設定 → 綁定手機 → **複製綁定連結**。不是短綁定碼，也不是 Google 帳密。若匯入時沒出現問題，直接編輯捷徑上方「文字」動作，把「貼上小帳的綁定連結」替換掉。

綁定連結含帳本通行資料，只在自己的手機貼入。不要回傳聊天、不要把設定完成的捷徑分享給別人；公開範本不含任何真實憑證。

## 接上通知自動化

在 iOS 27 捷徑建立自動化：

1. 「收到通知」→ App 選 LINE。
2. 名稱／標題包含 `LINE錢包`；訊息包含 `付款完成`。名稱可能隨 LINE 版本不同，第一次收款通知時再核對。
3. 動作選「執行捷徑」→ `小帳LINE通知記帳`。
4. 展開動作的輸入欄，指定觸發通知的 **內文／訊息**，不要留空，也不要只傳 App 名稱。
5. 若系統提供執行方式，選「立即執行」。先在解鎖狀態用一則實際付款通知測試並允許檔案／網路權限；iOS 的鎖屏或自動化權限限制不由網站控制。

通知可能只包含付款金額與店家，不含品項；AI 不會因此取得購物明細。LINE Pay 綁定其他銀行卡時，通知不一定揭露實際扣款帳戶；本範本依你的需求固定提示為小帳的 LINE 帳戶。

## 網路中斷與重送

- 送出前先把原文、收件時間與識別碼保存在 iCloud Drive → Shortcuts → `小帳LINE待送出`。檔案不含通行碼。
- 只有 GAS 回傳**同一佇列 ID**後，才刪除該待送檔。這代表已接收，**不代表 AI 已完成記帳**。
- 網路錯誤時捷徑可能由 iOS 顯示連線錯誤，但原檔仍在。網路恢復後執行 `小帳LINE重送`，選取那份 JSON；沿用原 ID，不多寫交易。
- 不要把同一通知再執行「通知記帳」捷徑，那是新的請求。兩筆真的同金額消費仍會各自記帳，不以文字或金額判斷重複。
- 暫不安排 iOS 定時重送；先用實際通知確認可讀到的格式。GAS AI 判讀失敗時仍保留伺服器佇列，沒有捏造交易。
- 2048 字以上會被拒絕，不會默默截斷；勿手動拆成多筆付款，先核對通知。

背景審查完成後，在小帳同步即可看到；不需讓網站一直開著。若沒有出現，先查看 GAS 的 `小帳_語音佇列` 狀態與背景觸發器，不要重新建立新通知請求。

## 已驗證範圍

本機測試涵蓋完整原文、佇列入庫、無金額不建交易、重送去重、已審查資料回傳、超長拒絕及手機捷徑的變數／請求結構。`.shortcut` 使用 macOS 原生簽署；**尚未在你的 iPhone 上完成真實通知端到端驗收**，沒有寫入你的正式帳本。

重新產生簽署檔：`node ios-shortcuts/build.mjs`（需要 macOS 的 `shortcuts sign`）。

平台參考：[Apple 通知自動化](https://support.apple.com/en-euro/guide/shortcuts/apd932ff833f/ios)、[捷徑 API 請求](https://support.apple.com/en-euro/guide/shortcuts/apd58d46713f/ios)。
